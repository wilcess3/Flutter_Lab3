Учебный проект по лабораторной работе №3. Приложение выводит приветствие "Hello World!" на градиентном фоне, демонстрируя базовые виджеты Flutter

## Запуск
1. Клонировать репозиторий:
   ```bash
   git clone <URL_репозитория>
2. Перейти в папку проекта:
    ```bash
    cd first_flutter_app
3. Установить зависимости
    ```bash
    flutter pub get
4. Запустить приложение в браузере
    ```bash
    flutter run -d chrome
## Что изучили в ходе работы
- Структуру Flutter-проекта и назначение основных папок (lib, web, test, img).

- Базовые виджеты: MaterialApp, Scaffold, Container, Center, Text, Column.

- Работу с градиентом через BoxDecoration и LinearGradient.

- Стилизацию текста через TextStyle (размер шрифта, цвет).

- Основы Git: коммиты, настройку .gitignore и пуш на GitHub.
